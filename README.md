# RAG-Electrodomus

## Initialisation du projet

### Environnement d'exécution

Dans le terminal :

```PowerShell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### Fichier des variables d'environnement

Copier le .env.example en .env et remplir avec vos données.

### Exécuter Pylint

```PowerShell
python -m pylint src/*
```
